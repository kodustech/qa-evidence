## Summary

Adds a new grade service module (`qa2700/grades.ts`) that defines the grade domain types and a service for recording student grades, computing a student's average, and evaluating honor-roll eligibility against an injected repository.

## Changes

- **New `GradeRecord` interface** — represents a single grade as `studentId`, `courseId`, and numeric `value`.
- **New `GradeRepository` interface** — declares the persistence contract the service depends on: `save(record)` and `findByStudent(studentId)`.
- **New `GradeService` class** — takes a `GradeRepository` via constructor injection and exposes three operations:
  - `recordGrade(studentId, courseId, value)` — builds a grade record, persists it through the repository, and returns the stored record.
  - `averageFor(studentId)` — loads the student's grades from the repository and computes their arithmetic mean.
  - `isHonorRoll(studentId)` — derives honor-roll status from the student's average using a threshold of 90.

## Known issues reported by automated review

The review agent flagged the following on the new module:

- **[high]** `recordGrade` persists grades without rejecting values outside the 0–100 range.
- **[medium]** `averageFor` yields `NaN` for an empty grade list instead of an explicit result.
- **[medium]** Off-by-one loop bound in `averageFor` reads past the end of the grades array.
- **[medium]** `isHonorRoll` compares a `Promise` rather than the awaited average.
