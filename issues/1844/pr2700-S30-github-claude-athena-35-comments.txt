## Summary

Adds a `Classroom` model and a helper to format a human-readable classroom label.

## Changes

- **`qa2700/classroom.ts`** (new):
  - Introduces a `Classroom` interface with `id`, `name`, and `capacity` fields.
  - Adds `formatClassroomLabel(room)`, which returns the classroom name followed by its seat count, e.g. `Room A (30 seats)`.

## Impact

Provides a single, consistent way to display classroom names alongside their capacity, so callers don't need to build this label string themselves.
