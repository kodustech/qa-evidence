**Off-by-one loop condition reads past end of grades array**

The `i <= grades.length` condition reads `undefined` at the last index, so `averageFor` throws a `TypeError` on every call, even an empty set. Change the loop to `i < grades.length`.



<details>
<summary>Prompt for LLM</summary>

````text
File qa2700/grades.ts, lines 24-26:

Off-by-one loop condition reads past end of grades array

The loop condition `i <= grades.length` iterates one index past the end, so `grades[i].value` dereferences `undefined` and throws `TypeError: Cannot read properties of undefined (reading 'value')`. Since it also triggers on an empty result set (i=0 <= 0), `averageFor` throws on every input instead of returning an average; use `i < grades.length`.

Suggested code:

for (let i = 0; i < grades.length; i++) {
    total += grades[i].value;
}
````

</details>

**isHonorRoll compares an unawaited Promise against 90, so it always returns false**

Comparing the unawaited `Promise` from `averageFor` against 90 is always `false`, so no student ever qualifies. Add `await` and drop the `as unknown as number` cast.



<details>
<summary>Prompt for LLM</summary>

````text
File qa2700/grades.ts, lines 31-32:

isHonorRoll compares an unawaited Promise against 90, so it always returns false

`averageFor` is async but its result is not awaited, so `avg` is a `Promise<number>` and `avg >= 90` compares an object against a number, which is always `false` — `isHonorRoll` never returns `true` for any student. The `as unknown as number` cast hides the compiler error; add `await` and drop the cast.

Suggested code:

const avg = await this.averageFor(studentId);
return avg >= 90;
````
