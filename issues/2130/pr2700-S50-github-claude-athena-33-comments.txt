## Summary

Adds a new grades module (`qa2700/grades.ts`) that introduces grade recording, per-student average calculation, and honor-roll evaluation.

## Changes

- Defines `GradeRecord` and `GradeRepository` interfaces to represent a student grade and the persistence operations for saving and retrieving grades by student.
- Adds `GradeService`, which:
  - Records a grade for a student/course pair and persists it through the repository.
  - Calculates a student's average by loading their grades and computing the mean.
  - Determines honor-roll eligibility based on whether the student's average meets the 90-point threshold.

## Review findings

- Grade values are saved without validation against the expected 0–100 range.
- The average loop uses `i <= grades.length`, which reads past the end of the array.
- `isHonorRoll` compares an unawaited `Promise`, so it does not evaluate the actual average and always returns `false`.
