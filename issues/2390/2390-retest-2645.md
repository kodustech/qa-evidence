Command: `API_NODE_ENV=test npx jest --config jest.config.ts --no-coverage <spec>`

"Interrupt" = start the spec, wait until a proxy process whose argv matches the target case appears
(`egress-proxy.js []` = E2B "a fence with no domains exits 0"; `egress-proxy.js ["api...` = `network fence script`),
then SIGKILL jest and every process under it except that proxy. The `finally` in `runFence` never runs,
so the proxy is left re-parented and listening. Same procedure as the 2026-11-19 run
([2390-local-repro.md](https://kodustech.github.io/qa-evidence/issues/2390/2390-local-repro.md)).

## Interrupt script
```bash
#!/bin/bash
# usage: interrupt.sh <worktree> <logprefix> <argv-regex for the proxy to wait for>
W=$1; L=$2; PAT=$3
cd $W
API_NODE_ENV=test npx jest --config jest.config.ts --no-coverage libs/code-review/infrastructure/agents/custom-agent-cli/cli-sandbox-scripts.spec.ts > $L.interrupted.log 2>&1 &
NPX=$!
desc() { for c in $(pgrep -P $1); do echo $c; desc $c; done; }
for i in $(seq 1 6000); do
  P=""
  for c in $(desc $NPX); do
    if ps -o command= -p $c 2>/dev/null | command grep -Eq "kcli-stubs-[^ ]*/egress-proxy.js $PAT"; then P=$c; break; fi
  done
  if [ -n "$P" ]; then
    TREE="$NPX $(desc $NPX | tr '\n' ' ')"
    KILL=""; for t in $TREE; do [ "$t" != "$P" ] && KILL="$KILL $t"; done
    kill -STOP $KILL 2>/dev/null; kill -9 $KILL 2>/dev/null
    break
  fi
  sleep 0.02
done
echo "proxy pid seen: $P"
sleep 1
echo "--- leftover proxy:"
pgrep -fl "kcli-stubs-[^ ]*/egress-proxy.js" | sed -E "s#/[^ ]*/(kcli-stubs-[^/ ]*)#.../\1#g" | cut -c1-200
for p in $(pgrep -f "kcli-stubs-[^ ]*/egress-proxy.js"); do lsof -nP -a -p $p -iTCP -sTCP:LISTEN | tail -n +2 | awk "{print \$1,\$2,\$9}"; done
```
