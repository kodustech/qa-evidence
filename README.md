# qa-evidence

Screenshots and videos from QA validation of [kodus-ai](https://github.com/kodustech/kodus-ai) issues.

- One folder per issue: `issues/<number>/`.
- File names say what they prove: `01-rule-evaluated.png`, `02-bug-repro.webm`.
- QA environment only. Nothing here comes from production or customer data; keys and passwords are masked before upload.

The issue comment that cites a file links to it here.

Browse and play everything in the browser at https://kodustech.github.io/qa-evidence/ (one issue: `#<number>`). Direct file links work too: `https://kodustech.github.io/qa-evidence/issues/<number>/<file>`.
